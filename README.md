# cm-staff-placement

건설사업관리용역 현장 직원 배치 관리 (프로토타입)

현장별 직원의 **계약배치 · 실제배치 · 변경 예정 배치**를 한 화면에서 확인하고,
엑셀 파일을 업로드하면 **중복 배치 인원을 자동으로 찾아주는** 웹 앱입니다.

> 모든 기능이 **브라우저 안에서만(완전 로컬) 동작**합니다.
> 데이터는 서버로 전송되지 않으며, 각자 컴퓨터 브라우저에만 임시 저장됩니다.

---

## 1. 파일 받기

이 저장소를 다운로드하거나, git이 있으면 클론합니다.

```bash
git clone https://github.com/gittaeo/cm-staff-placement.git
cd cm-staff-placement
```

**필요한 파일은 `index.html` 하나뿐입니다.**
메신저/이메일로 받았으면 그 파일을 바탕화면 등에 두면 됩니다.

---

## 2. 실행 방법 (두 가지 중 하나)

### 방법 A. 파일을 바로 열기 (가장 간단)

- `index.html`을 **더블클릭**하면 브라우저에서 바로 실행됩니다.
- 설치할 것 없음, 인터넷 불필요, 회사 PC에서 그대로 사용 가능.

### 방법 B. cmd에서 로컬 서버로 실행 (URL로 접속)

1. **시작 → `cmd`** 실행 후, 파일이 있는 폴더로 이동:

```bash
cd 경로\cm-staff-placement
```

2. 아래 명령으로 로컬 서버 실행 (Python 필요):

```bash
python -m http.server 8233
```

3. 브라우저 주소창에 아래 주소 입력:

```
http://127.0.0.1:8233/
```

종료하려면 cmd 창에서 `Ctrl + C` 를 누르면 됩니다.

---

## 3. 사용 방법

1. **엑셀 업로드 · 중복 인원 스캔** — 전체 배치 파일(`.xlsx` / `.xlsm` / `.csv`)을 업로드
   - 컬럼 매핑(현장명 · 직원명 · 직무 · 시작일 · 종료일 · 구분)을 확인하고 **임포트**
   - 임포트한 파일 안에서 **중복 배치 인원**이 자동으로 표시됩니다
   - 누락·오류 행(직원명/현장명 없음, 시작·종료일 누락, 기간 역전)은 건수와 사유로 안내
2. **전체 배치 현황** — 현장별 직원 배치 타임라인, 계약/실제/변경 예정 구분, 중복 강조 표시
3. **배치 관리** — 현장·직원·배치 등록/수정/삭제, 변경 이력, 직원별 이력
4. **AI 점검·요약** — 중복 배치 · 배치 변경 내용 · 계약배치 vs 실제배치 차이를 요약
   - 기본은 **완전 로컬 분석** (데이터가 브라우저 밖으로 나가지 않음)
   - 설정에서 "외부 전송"을 켜야만 Gemini로 데이터가 나가므로, 대외비 자료는 절대 켜지 마세요
5. **엑셀 내려받기** — 현장별/직원별 선택 후 배치 현황을 엑셀(XML 스프레드시트)로 저장

## 4. 대외비 보안 주의 (중요)

- 데이터는 **각자 브라우저에만 저장**됩니다. 공유가 필요하면 엑셀 내려받기로 파일을 주고받으세요.
- **실제 업무 데이터 파일(엑셀, 내려받은 XML)은 이 저장소에 절대 커밋하지 마세요.**
  `git add` 하기 전에 업로드용 파일이 있는지 반드시 확인하세요.
- **GitHub Pages는 켜지 마세요.** Pages URL은 인터넷에 공개됩니다.
- 이 저장소는 **private**으로만 유지하세요.
